Поддерживаются Windows 11 и Windows 10 начиная со сборки 19045. .NET 10 уже включён. Исполняемые файлы поставляются без цифровой подписи.

## Что нового

- Четыре вида осадков. Снег можно смахнуть с окна, собрать в снежок или сложить в снеговика.
- Новая боковая навигация, светлая и тёмная темы, управление с клавиатуры и предпросмотр погоды.
- Исправлено повторное открытие окна из трея и освобождение ресурсов рендера. Повреждённый файл настроек сохраняется в резервной копии перед записью новых параметров.
- При обновлении читаются настройки прежнего «Тихого снега» из `%LOCALAPPDATA%\QuietSnow`. Удаление программы сохраняет эту папку.

## English

Flurryveil brings snow, rain, autumn leaves, and cherry blossoms to the Windows desktop. This release adds redesigned settings with light and dark themes, keyboard navigation, and a live weather status. It also improves tray reactivation, settings recovery, and renderer cleanup.

Pick the Windows installer or extract the portable ZIP. Both x64 packages include .NET 10. Settings from previous QuietSnow builds are retained.
