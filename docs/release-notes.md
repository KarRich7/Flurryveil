# Flurryveil 1.0.0

Flurryveil brings snow, rain, autumn leaves, and cherry blossoms to the Windows desktop. Snow settles on window edges and the taskbar. You can sweep it away or roll it into snowballs and build snowmen.

Settings now have four sections, light and dark themes, and keyboard navigation. The weather preview reports when effects are active or paused. The renderer still supports Direct3D and a GDI fallback, and this release fixes resource cleanup when Windows recreates an overlay window.

## Downloads

- **Setup.exe** installs Flurryveil for the current user and offers an optional desktop shortcut.
- **Portable.zip** contains a self-contained executable and .NET runtime notices. Extract the archive before running it.
- **SHA256SUMS.txt** contains checksums for both packages.

The Windows x64 packages contain the .NET 10 runtime and are unsigned. Settings from «Тихий снег» are read from the existing QuietSnow folder. Settings are kept when updating or uninstalling.
